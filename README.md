# Ruins of the Ember Temple

An action-packed 2.5D endless runner game built with vanilla HTML5, CSS3, and JavaScript canvas.

🎮 **Live Demo:** [https://amshivang.github.io/temple/](https://amshivang.github.io/temple/)

## Overview
Dodge ancient ruins, slide under crumbling pillars, jump across hazards, and collect ember coins in a forgotten mystical world.

## Controls
- **Arrow Left / Right (or A / D):** Switch lanes
- **Arrow Up (or W / Space):** Jump
- **Arrow Down (or S):** Slide
- **Escape / P:** Pause / Resume

Supports touch swipe controls on mobile devices!

## Features
- Smooth 60 FPS Canvas rendering
- Dynamic obstacles, power-ups, and multiplier mechanics
- Responsive design for desktop and mobile browsers
- Atmospheric visuals and particle effects
- No external runtime dependencies

## Local Development
Open `index.html` in any modern web browser or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
